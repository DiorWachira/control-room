1. WHAT THIS IS
---------------
Control Room watches my three live apps, gives each an error budget, and when a budget
burns too fast it opens a ticket in Resolve (my service desk) with the SLA clock running,
pages me on Telegram, keeps a timeline and drafts a postmortem. A GitHub Action blocks
deploys while a budget is under its floor.

The apps:
  Resolve    Next.js 15, Prisma, Neon Postgres, Vercel           (also the incident queue)
  RepoLens   Python stdlib + JS, Render free tier (sleeps),       Gemini Examiner with a
             model fallback chain
  JobBridge  FastAPI, React, PostgreSQL, Neo4j, Docker Compose on a VM

Method: multi-window, multi-burn-rate alerts (Google SRE Workbook, "Alerting on SLOs").
  burn rate = error ratio / (1 - objective)
  page   14.4x on 1h AND 5m   (2% of budget in an hour)
  page   6x    on 6h AND 30m  (5% in six hours)
  ticket 1x    on 3d AND 6h   (10% in three days)
  Both windows must exceed the threshold. The short window gives a fast reset.

Acceptance criteria from the spec (all covered by engine/tests/test_alerting.py):
  - A 2-minute blip does not page; a sustained 5xx spike pages in the expected window.
  - A firing alert creates exactly one Resolve ticket and resolves it when the burn stops.
  - The deploy gate blocks a deploy in a drill when the budget is exhausted.
    (Unit-tested at the API; the real drill is M5.)

3. RUN IT
---------
Engine:
  cd engine
  python -m venv .venv
  .venv\Scripts\pip install -e ".[dev]"
  .venv\Scripts\python -m pytest -q
  .venv\Scripts\python -m uvicorn controlroom.api:app --reload --port 8000
Web (dev):
  cd web && npm install && npm run dev          -> http://localhost:5173
Web (served by engine):
  cd web && npm run build                       -> http://localhost:8000
Live mode: set PROMETHEUS_URL (see .env.example). Without it the API serves the replay.

5. KNOWN GAPS AND GOTCHAS
-------------------------
- Rolling windows forget. On the budget chart RepoLens jumps up on 28 Oct when the 30 Sep
  outage ages out. That is correct; the caption explains it. Don't "fix" it.
- The incident moved to Monitoring at 10:40 (slow tier), not 10:16 as the design canvas
  said. Engine is right; see DECISIONS.md.
- The replay "now" is fixed at 2026-11-08 10:52 EAT (scenario.NOW). The SLA countdown on the
  incident page starts from that snapshot and ticks in real time from page load.
- ProfileSource assumes steady traffic (time-weighted ratios). Prometheus ratios are
  event-weighted. Fine for the replay; don't compare them numerically in tests.
- Budgets replay advances one engine minute every 250 ms (500 ms with reduced motion).
  The flow ticks are hidden under prefers-reduced-motion; values still update.
- Status 404 / fault / loading screens exist (components.tsx). There is no toast system yet.
- Historic incidents before the replay (RSV-1031, 1024, 1017, 1009) are static records in
  scenario.HISTORY and are not clickable; in live mode they come from Resolve.
- Windows dev: the preview tool may pick another project's launch config; start the engine
  with uvicorn directly if that happens.
- Python 3.14 locally, CI pins 3.12; keep syntax compatible with 3.11.


6. DESIGN SYSTEM (keep it consistent)
-------------------------------------
Concept "House Lights": a 1960s mission operations room. One big board (dark projection
screen with plotboard grid, dark in both modes) over a row of sage consoles.
Tokens (web/src/styles.css):
  wall #E6DDC8  console #AAB08F  console-deep #7C8462  ink #1D2115  board #1B1F18
  lamps: white #F1E8CA (nominal/advisory), amber #E59C2F (budget burning ONLY),
         red #A9412F (breach/outage ONLY)
  dark ("house lights down"): wall #11130D, console #2A2F21, ink #E6E0CA
Type: Barlow Condensed (display, plates, lamp legends), Barlow (body), Share Tech Mono (data).
Rules: tight radii (2px), hard 8px "kick plate" shadows, no glow/blur/gradients, focus ring
uses ink not amber, every animation off under prefers-reduced-motion.
Signature pieces: draining budget tank + gate floor; incident strip sliding in from the
edge; annunciator riser + master caution + lamp test; guarded deploy-gate switch.
Design canvas: https://claude.ai/artifact/NpTxuU7g2miz56FNBYwxWC
Heads-up: ~/.claude/CLAUDE.md now lists annunciator lamps as retired for future projects.
They stay here because Control Room's brief asked for them; don't reuse them elsewhere.
